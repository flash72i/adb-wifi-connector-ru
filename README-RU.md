# ADB Wi-Fi Коннектор RU — версия 2.7.0

Русская сборка для беспроводной отладки Android по Wi-Fi (Electron, Windows x64).
В комплекте: adb (Android SDK Platform-Tools, © Google) и scrcpy.

## Что нового в 2.7.0 (по вашим замечаниям)

**Скорость подключения**
- Фаза «Сопряжение выполнено. Подключение…» больше не висит десятки секунд: поиск порта
  отладки теперь начинается СРАЗУ с ранним выходом на первом найденном порту (~1–2 с
  вместо полного свипа на ~24 с), а опрос «adb devices» и свип идут гонкой — кто первый
  найдёт телефон, тот и подключает. Типичное время подключения: 3–8 секунд.
- «Автопоиск портов» при сопряжении по коду ускорен тем же способом, плюс сразу пробует
  соседние порты (порт отладки обычно рядом с портом сопряжения).
- Кнопка «Найти порт» тоже стала мгновенной.

**Диагностика (категория «mDNS adb» снова информативна)**
- Раздел «mDNS-сервисы (adb mdns services)» показывает СЫРОЙ вывод команды — видно всё,
  даже то, что парсер не понял. Пустой список — жёлтое предупреждение с честным пояснением
  (сервисы видны только пока на телефоне открыт экран «Беспроводная отладка»), а не ошибка.
- Добавлены два новых раздела: собственное mDNS-обнаружение и unicast-обход подсети
  (для роутеров, которые режут multicast — как у вас).

**Трансляция экрана**
- Рамка телефона теперь точно ПО РАЗМЕРУ видео: окно трансляции обтекает кадр без
  «пустых полей» — телефон и картинка одинаковой величины, масштаб честный.

**Файлы — вид как в Проводнике Windows**
- Три режима одним переключателем: ☰ Список (с размерами и датами), ▦ Значки,
  ▣ Огромные значки — с живыми миниатюрами фотографий прямо в сетке. Выбор запоминается.
- Иконки APK-файлов — РОДНЫЕ: иконка приложения подгружается из APK и кэшируется,
  в углу — маленький зелёный Android-бейдж. Иконка появляется и в «свойствах»,
  вместе с именем приложения, пакетом и версией.
- Текстовые файлы ВСЕХ форматов открываются встроенным просмотрщиком (UTF-8/1251),
  с переносом строк и кнопками «Скачать»/«Открыть на ПК».
- PDF открывается встроенным просмотрщиком (pdf.js): постранично, со стрелками.
- HTML-файлы открываются в СИСТЕМНОМ браузере — там работают все скрипты, стили и CDN
  (ваша three.js-анимация с CDN в iframe бы не заработала, а в браузере — да).
- Архивы: в свойствах появилась кнопка «Распаковать в папку» — архив разворачивается
  в папку с именем архива, в ТОЙ ЖЕ папке устройства. Поддержка: ZIP/JAR (unzip на
  устройстве; если его нет — скачаем, распакуем на ПК и зальём обратно), TAR, TAR.GZ/BZ2/XZ.
  RAR/7z честно отклоняются (распаковщиков на Android нет) с подсказкой.

**Фото**
- Просмотрщик получил ПЛЁНКУ-карусель внизу: маленькие карточки всех фото папки,
  как в Windows. Клик по карточке — переход к снимку, текущая подсвечена и сама
  подезжает в центр; миниатюры подгружаются лениво.

**Плеер**
- ВИДЕО ПОЧИНЕНО: разблокировано автовоспроизведение (плеер открывается и сразу играет,
  без чёрного экрана и без нажатий).
- ДВЕ кнопки полного экрана: «В окне» (растянуть внутри программы) и «На весь монитор» —
  настоящий фулскрин компьютера (тоже добавлен и в просмотрщик фото).
- Формат, который браузер не играет (mkv с редким кодеком и т.п.): теперь есть кнопки
  «Скачать» и «На ПК» прямо в плеере — файл скачается и откроется СИСТЕМНЫМ плеером,
  который играет ВСЁ.
- ВИЗУАЛИЗАЦИИ: 10 штук, с номерами и названиями, листаются стрелками ◀ ▶ (или клавишей V,
  или Shift+стрелки), выбор запоминается между запусками. Анимация живёт ВСЕГДА, пока
  открыт плеер (даже на паузе), а во время музыки — реагирует на бас/середину/верх напрямую.
  Внутри — переосмысления ваших анимаций: «Куб-рой», «Нейросеть», «Квантовая сфера»,
  «Тессеракт 4D», «Гиперпрыжок», «Космос», «Светлячки» + классические «Столбики»,
  «Волна», «Круг».

**Процессы**
- Кнопки-фильтры «Все процессы» / «Только приложения» — то, чего не хватало.
- У процессов появились ИКОНКИ: родная иконка приложения из кэша (без скачивания APK),
  у приложений без кэша — зелёный Android-робот, у системных служб — шестерёнка.

**APK с рабочего стола (ассоциация файлов)**
- Двойной клик по .apk/.xapk/.obb теперь открывает ОТДЕЛЬНОЕ маленькое окно — основная
  программа не запускается. Окно перетаскивается по рабочему столу за заголовок; внутри:
  родная иконка, имя, версия и пакет приложения, список устройств, кнопка «Подключить…»
  по IP прямо из окошка и установка с прогрессом.
- Честное ограничение Windows: иконку КОНКРЕТНОГО apk-файла на рабочем столе показывает
  сам Проводник, и без COM-расширения она одна на все apk (иконка программы). Родные
  иконки показываются в наших окнах — куда двойной клик и ведёт.

**Прочее**

## Как подключить

1. На телефоне: «Параметры разработчика» → «Беспроводная отладка».
2. Первый раз: «QR-код на телефон» (самый быстрый) или код сопряжения.
3. Дальше — по IP из истории/избранного в один клик.

Телефон и компьютер должны быть в одной сети Wi-Fi; сеть Windows — «Частная».

## Журнал и поддержка

При проблемах пришлите `app.log` из корня папки программы (записываются только ошибки).
Все сохранения — в папке «Сохранения» рядом с программой.
