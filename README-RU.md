# ADB Wi-Fi Коннектор RU — версия 2.8.0

Русская сборка для беспроводной отладки Android по Wi-Fi (Electron, Windows x64).
В комплекте: adb (Android SDK Platform-Tools, © Google) и scrcpy.

## Что нового в 2.8.0

**QR-подключение — работает и мгновенное**
- Найдена причина «QR не работает»: прямой перебор портов искал только в диапазоне
  30000–44999, а Android выдаёт порты беспроводной отладки из эфемерного диапазона
  **32768–60999**. На сетях, где роутер режет multicast (и mDNS не работает вовсе),
  порт сопряжения выше 44999 НЕ НАХОДИЛСЯ — теперь перебор покрывает весь диапазон,
  и каждый найденный порт пробуется НЕМЕДЛЕННО, не дожидаясь конца сканирования.
- QR-код показывается **сразу под кнопкой «QR-код на телефон»** (~156×149 px) —
  без отдельного окна, без повторных нажатий и без чёрной заглушки. Шаги
  «ищу телефон → сопряжение → подключено» видны мгновенно строкой под кодом.
- Поле IP сопряжения — 190×47 px; кнопка «Сопрягнуть и подключить» переименована в «Подключить».

**Файловый менеджер — как в Проводнике**
- **Правая кнопка мыши** на файле/папке: Открыть, Скачать, Копировать, Вырезать,
  Переместить в…, Переименовать, В архив ZIP, Открыть архив, Свойства, Удалить.
- **Копирование и перемещение** между любыми папками и томами: память телефона ⟷ флешка.
  Панель «Вставить сюда» + «Переместить в…/Копировать в…» с выбором папки.
- **Переименование** файлов и папок; **создание файлов** (например .txt).
- **Архивы**: «Открыть архив (не распаковывая)» — оглавление ZIP/JAR, просмотр файла
  из архива в один клик, «Извлечь отмеченные», «Распаковать всё в папку»;
  «Добавить в архив ZIP» собирает ZIP из файлов/папок (сжатие на ПК).
- **Категории со всего телефона**: чипы «Все фото», «Вся музыка», «Всё видео»,
  «Документы» — виртуальная папка со ВСЕМИ файлами категории со всех папок устройства.
- **Вид — плавный, как в Проводнике Windows**: тяните ползунок — размер значков
  меняется непрерывно (76→250 px), останавливайтесь где нужно; миниатюры фото
  включаются уже со среднего размера.
- **Просмотр DOCX** (текст, заголовки, жирный/курсив, таблицы) и **контактов VCF**
  (карточки: имена, телефоны, email, организация — прямо в программе).
- **APK на телефоне**: свойства файла показывают имя/иконку/версию приложения,
  установленную на телефоне версию, кто новее, и кнопку **«Установить на телефон»**
  (pm install -r — без скачивания на ПК). Адаптивные иконки (Android 8+) распознаются —
  иконки появились у приложений, где раньше был только робот.
- Фикс «прозрачной щели»: при прокрутке больше не проглядывает строка файла
  под закреплённой панелью.

**USB/OTG-флешки — инструменты как на ПК**
Кнопка «⚙ Инструменты флешки» рядом с флешкой: **Форматировать**, **Сменить метку**,
**Проверить и исправить** (fsck, если есть; иначе перемонтирование — лечит «повреждённую»
ФС без удаления файлов), **Извлечь** и **ПРОВЕРКА НА ФЕЙКОВУЮ ПАМЯТЬ**: заливает флешку
блоками с маркерами, читает назад и называет РЕАЛЬНЫЙ объём (классическая проверка
«32 ГБ, а реально 16»). Три скорости проверки; результат — в отчёте.

**Плеер**
- Звук и видео играют через **ПРЯМОЕ воспроизведение** — «чёрный экран / запускаю
  и ничего» больше невозможно по умолчанию. Эквалайзер включается кнопкой EQ,
  звук переключается с сохранением позиции.

**Приложения и процессы**
- **▶ Запустить** — в списке приложений и в свойствах: приложение открывается на телефоне.
- Очистить данные/кэш, остановить, включить/отключить — выполняются **сразу**, без
  вылезающих за окно подтверждений. Полное удаление — единственный вопрос, и то с
  галочкой «Больше не спрашивать» (один раз).
- «Убить» процесс — с галочкой «Больше не спрашивать»; вкладка процессов
  **обновляется сама каждые 3 секунды**: запустили приложение на телефоне — оно
  появляется в списке мгновенно.

**Установка APK**
- ОДНО подтверждение в программе — и **без вопросов на самом телефоне**: на время
  очереди отключается проверка adb-установок (возвращается после), на MIUI
  дополнительно снимается «Установка через USB».
- Зона перетаскивания сжимается, когда в списке уже есть файлы, — список занимает
  весь экран, а не «полэкрана на один файл».

**Windows**
- Значок .apk/.xapk на рабочем столе: DefaultIcon теперь указывает на настоящий
  .ico-файл + полный сброс кэша значков Проводника — белый значок больше не задерживается.
- Мини-окно APK: кнопка «Закрыть» работает (раньше закрывал только крестик вверху).

## Как подключить

1. На телефоне: «Параметры разработчика» → «Беспроводная отладка».
2. Первый раз: «QR-код на телефон» (самый быстрый) или код сопряжения.
3. Дальше — по IP из истории/избранного в один клик.

Телефон и компьютер должны быть в одной сети Wi-Fi; сеть Windows — «Частная».

## Состав папки (портативная версия)

- `ADB-WiFi-Connector-RU.exe` — запуск (лаунчер);
- `APP\` — среда Electron и само приложение (`APP\resources\app` — исходники);
- `APP\resources\adb` — adb.exe; `APP\resources\scrcpy` — scrcpy;
- `Сохранения\` — конфиг, история, кэш иконок, скриншоты/видео;
- `app.log` — журнал (только ошибки + диагностика).

Версия 2.8.0; исходный код — в репозитории и в папке SOURCE_v2.8.0 архива.
Лицензия MIT; adb — Android SDK Platform-Tools (Google), scrcpy — Apache-2.0.

## Журнал и поддержка

При проблемах пришлите `app.log` из корня папки программы (записываются только ошибки).
Все сохранения — в папке «Сохранения» рядом с программой.
