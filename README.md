# ADB Wi-Fi Коннектор (RU)

Беспроводная отладка Android по Wi-Fi — русская портативная программа для Windows x64.
Открытая реализация по мотивам проприетарного приложения: без пробного периода, рекламы
и встроенных покупок. В комплекте adb (Android SDK Platform-Tools) и scrcpy.

## Возможности
- Подключение по IP, сопряжение по коду, QR-подключение (Android 11+), автопоиск портов
- Встроенная трансляция экрана (h264 + простой режим) и внешнее окно scrcpy
- Файловый менеджер (обе стороны, OTG-флешки, просмотр фото/видео/музыки/PDF/текстов/HTML, архивы)
- Менеджер приложений и процессов (иконки, имена, debloat, пакетные операции)
- Установка APK/XAPK/APKS/APKM/OBB, ассоциации файлов Windows
- Терминал adb shell с библиотекой команд, logcat, диагностика, запись экрана, скриншоты

## Сборка
См. README-BUILD.md. Быстрые правки — без пересборки: отредактируйте файлы в
APP/resources/app и перезапустите программу.
